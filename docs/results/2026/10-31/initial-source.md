## Review and static corrections

Source review covered the shared producer and renderer, CLI filesystem paths,
owned writes/cleanup and the reader/workspace DOM/state boundaries. Two agents
independently reviewed source. Concrete findings were corrected before sealing:

- Canonical serialized JSON has a 5 MiB byte limit in addition to Markdown
  budgets, so a valid producer cannot exceed the reader's import limit after
  escaping or pretty formatting.
- Heading IDs are namespaced away from interface controls. A per-stem counter
  and 2,048-heading limit avoid quadratic repeated-heading work. Resolved link
  metadata lets the CLI check actual same/cross-page heading targets.
- Candidate pages are all render-preflighted before a browser project commits;
  invalid rendering cannot partially replace the previous workspace or crash
  search only when a nonselected page is examined.
- Browser history retains its validated position after reload, preserving URL
  and editor identity when the user declines navigation with unapplied edits.
- Clearing the saved copy works without a published project, verifies only
  Clero's key and retains current tab input when offline. Field limits match
  the shared model. Save acknowledgement requires exact storage readback.
- File reads are allocation-bounded before decoding, including growth during
  reading. Existing output directories are refused; partial-error cleanup
  checks recorded ownership and preserves unexpected changes.

Node syntax checks do not import or execute product/test modules. All seven
JavaScript modules/test files were prepared for this check. Static HTML readback
found 63 unique IDs, 55 matching JS targets and three existing local assets.
Only shared renderer output enters the two article `innerHTML` assignments.
The one published-project fetch is same-origin, stream-bounded at 5 MiB,
redirect-refusing and aborts after 12 seconds. User labels use DOM text.
The final staged whitespace/import/JSON/case inventory and source fingerprints
are recorded in [publisher-source.json](publisher-source.json).
