From workspace to a published website

Export this workspace JSON, then pass that actual file to the Clero CLI from its repository:

node bin/clero.mjs check ./clero-workspace.json
node bin/clero.mjs build ./clero-workspace.json --out ./my-docs-site

Replace the example filename with your downloaded JSON filename. The build creates a new static output directory and refuses an existing destination. It does not upload automatically; choose explicitly where to host the resulting website.

Prefer Markdown files? node bin/clero.mjs init ./my-docs creates a source directory with clero.json. The same check and build commands accept that directory.
