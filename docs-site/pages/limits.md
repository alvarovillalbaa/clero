# Know the current scope

Clero is an initial documentation publisher: Markdown source, a shared
project format, a reader, local workspace editing and static output.

## Source and publishing

The project is inspired by the documentation-publishing category. It does not
claim full Mintlify feature or configuration compatibility. The current
Markdown renderer is a bounded subset, not a CommonMark conformance claim.

Supported URL schemes are HTTP, HTTPS and email links, plus validated internal
pages and heading anchors. A syntactically accepted external link is not a
reputation, availability or destination-content guarantee.

## Separate services

Hosted team accounts, Git-provider synchronization, automatic publishing for
other users, API specification tools, MDX components, AI assistants and
analytics are not implemented. Nothing in the workspace pretends those
services are connected.

## Verification

Authored checks and source/build evidence are tracked in the public repository.
A successful deployment proves a build reached its host; interactive browser,
clipboard, storage, keyboard and real-device acceptance need their own checks.
