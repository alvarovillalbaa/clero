# Give good ideas a clear place to live.

Clero turns Markdown into a focused documentation site. Keep your source,
organize a useful path through it, and give readers room to understand.

## Start with the work

Your documentation belongs to you. A project is a collection of Markdown
pages and a small configuration file. The reader, editor and publishing tool
use the same versioned project format.

- Write in a text editor or open **Workspace** to try changes here.
- Organize pages into a clear navigation with stable links.
- Search your documentation without sending queries to another service.
- Export your workspace and build a static site you can host yourself.

## A quieter reading experience

Pages have a contents outline, code-copy controls and a light or dark theme.
Navigation works with direct page links and browser history. The workspace
keeps drafts on this device; publishing is a separate, explicit step.

> This site is itself a Clero project. The content you are reading is authored
> Markdown, published with the same tool available in the repository.

Begin with the [quickstart](quickstart.md), or learn about the [workspace](workspace.md).
